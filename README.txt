【快速开始】
  1. 双击 init.bat      —— 仅第一次需要：创建 conda 环境 + 装依赖
  2. 双击 start.bat     —— 以后都用这个：黑窗一闪即逝，直接弹主界面
  3. 双击 debug.bat     —— 出问题才用：保留黑窗，把报错原样显示出来

【使用流程】
  ① 导入素材   把视频(mp4/mkv/webm…)和字幕(srt/vtt)一起拖进窗口
               ——也可以分开拖，或点"选择视频/选择字幕"
               系统立刻对照你的知识库筛出生词
  ② 学词       逐张卡片学：音标 / 美英发音 / 中文释义 / 英文释义
               / 视频原句 / 例句 / 词族；顺手点「已掌握」直接入库
  ③ 看视频     内置播放器 + 右侧"生词实时面板"（不限学习列表）
               · 面板顶部有「弹出规则」卡：按知识库 / 按词频二选一，
                 词频模式用滑块现场拖上限，改完立刻生效（详见下文）
               · 字幕里所有知识库外的词都高亮，颜色 = 掌握程度：
                 橙=陌生 / 蓝=学习中 / 绿=已掌握；点词直接看详情+发音
               · 面板按出现轮次分层：刚刚这句 / 上一句 / 更早
               · 每张卡：单词 + 音标 + 中文释义 + 见过几次
               · 按钮：发音 / 掌握（立即写库）/ 加入学习 / 不再显示
               · 出现次数到阈值自动纳入知识库，面板颜色实时跟着变
               没有视频文件时也能用，字幕会按时间自动推进
               ★ 影院模式：双击画面或按 F 进入——画面放大、窗口最大化，
                 只保留 视频 + 字幕 + 右侧生词面板；Esc 或再按 F 退出
  ④ 拼写测验   看中文释义拼单词，可要首字母提示；答错的词可重测
  ⑤ 我的词库   全部词汇一览：搜索 / 筛选（含"已屏蔽"）/ 恢复屏蔽词 / 导出备份

【继续学习】
  · 首页下方"继续学习"列出所有历史素材（生词数 / 已掌握进度 / 上次打开）
  · 点「看视频」或双击 → 原视频+字幕直接载入接着复习；离开时自动记录进度

【v1.2 更新：音画同步 · 流畅度 · 缓存 · 影院模式】
  · 音画同步重做：视频帧不再"各走各的钟"，改为全程锁定音频硬件时钟、
    逐帧漂移校正（落后就丢帧、没到点就等），长时间播放零漂移；
    顺带修掉了旧版固定延迟约 0.37s 的口型对不上问题
  · 流畅度：播放中的画面缩放改用低耗算法（约快 5 倍），暂停/静帧自动
    切回高质量重采样；生词状态走内存缓存，字幕渲染不再频繁查库
  · 最近视频缓存（5 个）：离开/暂停时自动记录视频、字幕、位置、倍速，
    再次打开同一个视频直接定位到上次位置（保留最近 5 个，
    data/cache/recent_videos.json）
  · 查词缓存（10000 条）：最近 1 万条查词常驻内存、释义秒出，
    查词历史落盘 data/cache/lookup_history.json
  · 影院模式：控制条点「影院模式」/ 双击画面 / 快捷键 F 进入，
    Esc 退出；进入后窗口最大化、解码宽度提到 1600，
    只显示 画面 + 字幕 + 右侧生词面板

【词汇水准】（⚙ 设置里的第一项）
  · 决定"默认已经认识多少词"，也就是筛生词时的基准线：
      起步 1000 / 初中 2000 / 高中 3500 / 四级 5000 / 六级 8000 / 高阶 15000
    （高中及以上会并入随程序自带的高中 3500 大纲词）
  · 随时可以切换：升级只补新词，降级只回收"没有任何学习痕迹"的词，
    你手动标记过、测验过、真实曝光过的词一律保留
  · 想从头再来：⚙ 设置 → 重置知识库（会清空词条/素材历史，建议先导出备份）

【弹出规则】（看视频页右侧面板顶部的卡片，切换 / 拖动即时生效）
  · 决定"字幕里哪些词要弹出并配解释"，两种口径二选一：
      按知识库（默认）→ 知识库外的词一律弹出，不做任何挑选，
                         已经认识的词不再打扰（程序不替你做取舍）
      按词频          → 不管在不在知识库，只看词频排名在上限以内的词，
                         上限用滑块现场拖：前 500 / 1000 / 2000 / 3000 /
                         5000 / 8000 / 12000 / 拖到最右 = 不限
  · 词频模式还有「跳过已掌握」开关：勾上时已经认识的词不列出来；
    如果某个区间全是认识的词，卡片会提示你取消勾选把它们也显示出来
  · 改规则会立刻重筛当前素材、重画字幕高亮和右侧面板，
    顶部徽章同步显示当前规则摘要

【导出知识库】（我的词库 → 导出 / 备份）
  · CSV（Excel 直接打开） / TSV（Anki 直接导入） / Markdown 表格
    / JSON / 纯文本单词表，都可以选择是否附带视频原句
  · 范围支持"当前筛选的词 / 全部 / 只要还没掌握的词"
  · 也可以直接「复制到剪贴板」，不落盘
  · 默认文件名带日期（EnglishLab-词库-20261002.csv），位置在桌面

【要不要联网 / 会不会烧 token】
  · 核心流程全部本机：SQLite 词库 data/lexicon.db、字幕解析、筛词、
    字幕高亮、掌握度、拼写测验、导出 —— 断网照常用
  · 联网只有两件事，全是免费公开接口，不需要账号和 API Key，
    也不涉及大模型，所以**不消耗任何 token、没有额度**：
      1. 查词（音标/释义/例句）→ 有道公开词典接口
      2. 发音 → 有道 dictvoice 下载 mp3，听过一次就缓存在 data/cache/audio
  · 整句翻译已移除：双语字幕的中文对照直接显示，没有中文的句子不再联网翻译
  · 所有查询结果都写进本地词典缓存，同一个词只请求一次
  · 断网时会缺：中文释义、发音；联网后再触发会自动补上
  · ⚙ 设置 →「联网与用量说明」里有同样的说明

【知识库规则】
  · 默认词汇水准 = 四级 5000 词（首次启动自动写入，可在设置里改档位）
  · 任意窗口顶部的搜索框：输入任何单词回车即可查询，
    并自行决定是否「加入知识库」
  · 一个词被"曝光"给你 5 次 → 自动纳入知识库（阈值可在设置里改），
    看视频过程中实时生效，不用手动点
  · 每个词都有「遇到过 N 次」的统计，到 50 次停止累加
  · 学词列表默认收前 100 个生词（按"覆盖句数×2+词频"排序，
    避免视频里的例子词霸榜）；看视频时不受这个数限制——
    只要是知识库外的词全部实时捕捉、高亮、给释义
  · 不想再看到某个词 → 面板里点「不再显示」，
    之后所有素材都不再高亮它；词库里可随时恢复
  · 知识库存放在 data/lexicon.db，词典与发音有本地缓存，可离线复用

【目录结构】
  init.bat / start.bat    环境初始化 / 日常启动
  debug.bat               排错模式（保留黑窗，显示完整 traceback）
  main.py                 程序入口
  requirements.txt        依赖清单（PyQt5 + requests）
  src/                    源码（core + ui）
  data/                   词库、缓存、设置
  data/vocab/freq20k.txt  英语词频表（2 万词，按频率排序，支撑水准与弹出规则）
  data/base3500.tsv       高中大纲词（带音标释义）
  samples/demo.srt        示例字幕，没有素材时可以先拿它跑一遍流程

【常见问题】
  · 双击 bat 报错 → 先双击 debug.bat，把黑窗里的红色报错发我，一眼就能定位
  · start.bat 没反应 / 弹"尚未初始化" → 先跑一次 init.bat
  · init.bat 说"没有找到 conda" → 把 Miniconda 装到
    C:\Users\你的用户名\miniconda3（或 Anaconda3）再重试
  · 内置播放器放不了某些格式 → 点「系统播放器」用外部程序打开
  · 查词失败 → 检查网络（用的是有道公开接口），释义有本地缓存
  · 想改自动掌握阈值 / 题量 / 生词上限 / 面板条数
    → 右上角 ⚙ 设置（弹出规则在看视频页右侧面板顶部现场调）
  · 启动报错看 error.log

【播放器与双语字幕（v1.1）】
  · 内置播放器改用 ffmpeg 直接解码（本机 Qt 多媒体后端起不来，之前黑屏就是它）
    画面逐帧渲染，音频走声卡，拖动进度条松手后才跳转
  · 找不到 ffmpeg 时界面会提示，可在 ⚙ 设置里手动指定 ffmpeg.exe 路径；
    requirements 里可选装 imageio-ffmpeg 作为兜底
  · 双语字幕规则：
      - 同一条字幕里"英文 + 中文"两行 → 直接对照显示
      - 英文一条、紧跟着中文一条（时间几乎相同）→ 自动配对
      - 完全没有中文 → 只显示英文原文（不做联网翻译）
  · 注意：pros/001 当前这份字幕是"前 9:48 英文 + 之后中文"两段拼接，
    时间上不重叠、无法逐句配对，英文部分只显示原文；
    想要原生对照效果，换标准双语 srt 即可

在这个空间中我要构建个人英语水平成长的系统，项目要求按照PRO.txt来，要求就是默认掌握的基础词汇是高中阶段的3500词，然后后续如果给用户曝光过五次以上或者用户明确指出已经掌握的词也纳入知识库。
我希望做这样一个系统，我一般会用TED视频作为学习材料，我会先讲视频下载转成srt，然后喂给系统，系统去知识库中核对，寻找未完全掌握的词汇，然后调用什么查词api之列的工具，将单词的信息发音啥的详细显示，最好能点击发声，所有单词都给一个统计指标就是遇到过的次数，统计到50次后停止。最好是这样，我拖入视频和srt文件，到时候播放视频的同时你在旁边实时显示最近用到的单词，便于快速过一遍。
总结以下工作流，用户拖入视频和srt文件，然后先根据知识库筛选，然后查词显示让用户先学习，等用户学习完了之后，就可以看视频，看视频的时候旁边实时显示对应前面学到的词汇，等全部看完后，再来一个根据意思拼写单词的环节检验学习效果，并且更新知识库。用户在过程中可以选择某个单词来查询，并且决定单词是否要直接纳入知识库。
